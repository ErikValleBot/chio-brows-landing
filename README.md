# Chio Brows - Landing Page

Landing page profesional para Chio Brows, estudio de micropigmentación en Querétaro.

## 📂 Estructura

```
chio-brows-landing/
├── index.html      # Homepage principal
├── styles.css      # Estilos y diseño responsive
```
